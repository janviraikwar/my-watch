# Premium Luxury Watch E-Commerce Website - Agent Instructions

This project is a premium luxury watch e-commerce website (e.g., "AETHER"). As an AI agent working on this project, you must adhere to the following product requirements and design guidelines:

## Core Brand & Design Identity
- **Vibe:** Minimal, Elegant, Modern, Premium, Sophisticated.
- **Visuals:** Consistent premium luxury identity. Smooth transitions, subtle animations, clean product cards, responsive layout.
- **Components:** High-quality imagery, clear typography ("Time, Designed for You."), subtle hover effects.

## Key Features & Pages
1. **Homepage:** Large premium hero section, Featured Collections (New Arrivals, Best Sellers, Men/Women).
2. **Shop / Collection:** Categories (All, Men's, Women's, etc.), Filters (Gender, Color, Price, Strap, Style), Sorting.
3. **Product Cards & Details:** High-quality images, zoom, comprehensive specs, Add to Cart / Wishlist, Reviews, rating.
4. **User Auth & Profile:** Mobile/Email signup/login. Dashboard with orders, wishlist, saved addresses, settings.
5. **Cart & Checkout:** Full checkout flow (Order summary, addresses, payment methods).
6. **Other Pages:** About Us (Brand story, craftsmanship), Reviews/Testimonials.
7. **Global Search:** Search by name, collection, category, style.

## Technical & Implementation Guidelines
- **Responsive Design:** Must work flawlessly across Desktop, Laptop, Tablet, and Mobile (using hamburger menu and mobile filters).
- **Navigation:** Clear access to Home, Watches, About, Contact, plus icons for Search, Wishlist, Cart, and Account.
- **State Management:** Ensure consistent state across Cart, Wishlist, and User Sessions.
- **Backend:** The project connects to a Supabase backend for data and auth. Ensure all integrations map correctly to the Supabase schema.

When generating, modifying, or reviewing code, always ensure the output aligns with this premium, luxurious aesthetic and satisfies all the PRD requirements above.
